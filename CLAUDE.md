# Preferensi Bahasa

Claude harus selalu merespons dalam Bahasa Indonesia.

Gunakan Bahasa Indonesia untuk:
- penjelasan
- rencana kerja
- ringkasan perubahan
- analisis bug
- instruksi terminal
- komentar terhadap kode

Tetap gunakan bahasa asli untuk:
- nama file
- nama folder
- command terminal
- syntax kode
- nama package/library
- istilah teknis yang umum dipakai developer
