# Instruksi Bahasa

- Selalu gunakan Bahasa Indonesia dalam semua jawaban, penjelasan, ringkasan, rencana, dan komentar.
- Jika user menulis dalam bahasa Inggris, tetap jawab dalam Bahasa Indonesia kecuali user meminta sebaliknya.
- Istilah teknis coding boleh tetap menggunakan bahasa Inggris jika lebih umum, misalnya: component, props, state, endpoint, deploy, build, error, bug.
- Jangan menerjemahkan nama file, nama variabel, nama package, path, command terminal, atau syntax kode.
- Untuk komentar kode, gunakan Bahasa Indonesia jika memungkinkan.
- Saat menjelaskan perubahan kode, gunakan gaya singkat, jelas, dan praktis.
