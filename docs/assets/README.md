# Assets Dokumentasi

Folder ini disediakan untuk aset pendukung dokumentasi RadioSBL App, seperti logo, diagram, atau gambar tutorial yang bukan hasil screenshot langsung dari aplikasi.

Catatan keamanan:
- gunakan aset dummy atau aset resmi yang memang boleh dibagikan;
- jangan menyimpan token, credential, nomor telepon pribadi, atau data user asli;
- jika perlu memakai contoh data, gunakan nama dan akun demo.
