# Link Streaming Radio SBL

Sumber: `docs/LINK_STREAM.txt`.

## Stream Langsung

```txt
https://pu.klikhost.com/proxy/sbl/stream
```

URL ini dipakai sebagai sumber audio utama aplikasi (`stationInfo.streamUrl`).

## Halaman Publik

```txt
sbl.pinrangkab.go.id/radio-stream
```

URL ini tetap disimpan sebagai halaman publik stream (`stationInfo.publicStreamPage`).
