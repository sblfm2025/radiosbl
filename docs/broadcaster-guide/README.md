# Panduan Penyiar

## Fungsi
Panduan ini membantu penyiar menjalankan alur harian: login, cek jadwal, absensi, request lagu, naskah AI, streaming, dan tukar jadwal.

## Cara Mengakses
Login ke aplikasi lalu gunakan menu bawah: `Beranda`, `Jadwal`, `Absensi`, `Request`, dan `Menu`.

## Langkah Kerja Harian
1. Buka `Dashboard` dan baca `Operational Briefing`.
2. Cek `Jadwal saya hari ini`.
3. Lakukan `Absensi` sebelum bertugas.
4. Saat on-air, buka `Request` untuk memantau request pendengar.
5. Gunakan `Naskah AI` untuk membuat cue, opening, bridging, atau closing.
6. Jika berhalangan, ajukan `Tukar Jadwal`.

## Catatan Penting
- Pastikan absensi dilakukan sebelum siaran.
- Request lagu harus diproses sesuai status: masuk, antrean, diputar, atau ditolak.
- Tukar jadwal berjalan antar penyiar: pemohon mengirim, penyiar pengganti menyetujui/menolak.

## Troubleshooting
| Masalah | Solusi |
| --- | --- |
| Tidak melihat menu Naskah AI | Pastikan role/permission AI aktif. |
| Request tidak tampil | Tekan sinkronkan atau buka ulang halaman. |
| Tidak bisa tukar jadwal | Pastikan slot milik penyiar terdeteksi dan kandidat pengganti tersedia. |
