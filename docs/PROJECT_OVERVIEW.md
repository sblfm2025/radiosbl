# LPPL Radio Suara Bumi Lasinrang Management System

**Tagline:** Suara Pinrang, Suara Kita

## Deskripsi Sistem

Aplikasi berbasis web Progressive Web App (PWA) untuk mendukung operasional LPPL Radio Suara Bumi Lasinrang, meliputi manajemen penyiar, absensi pegawai, jadwal siaran, liputan, live broadcast/OB, streaming radio, pengaduan masyarakat, YouTube Live, Discord, dan Gemini AI.

## Tujuan

- Digitalisasi operasional radio.
- Mengurangi proses manual absensi dan penjadwalan.
- Mempermudah koordinasi studio, liputan, dan OB.
- Menyediakan dashboard laporan.
- Menyediakan arsip digital berbasis Google Drive.

## Target Pengguna

- Super Admin
- Admin
- Pimpinan
- Penyiar
- Reporter
- Operator
- Karyawan
- Publik/Pendengar

## Stack

- React, Vite, TypeScript, TailwindCSS, PWA
- Firebase Auth, Firestore, Firebase Hosting
- Google Drive API untuk penyimpanan file
- Gemini AI
- OBS Studio, YouTube Live, Discord
