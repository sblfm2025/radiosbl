# Panduan Reporter

## Fungsi
Panduan ini membantu reporter melihat tugas liputan, mengirim update lapangan, dan menjaga deadline.

## Cara Mengakses
Login sebagai reporter, lalu buka menu `Event` atau `Liputan`.

## Langkah Penggunaan
1. Buka `Dashboard` untuk melihat prioritas tugas.
2. Buka `Event` untuk melihat daftar liputan.
3. Gunakan pencarian/filter status untuk menemukan tugas.
4. Periksa deadline dan catatan prioritas lapangan.
5. Upload dokumentasi sesuai instruksi internal.

## Catatan Penting
- Gunakan data dummy pada dokumentasi.
- Jangan menampilkan nomor pribadi narasumber atau dokumen internal sensitif.
- Pastikan koneksi stabil sebelum upload.

## Troubleshooting
| Masalah | Solusi |
| --- | --- |
| Tugas tidak tampil | Cek filter status dan pencarian. |
| Upload gagal | Cek koneksi, ukuran file, dan izin akses. |
| Deadline salah | Hubungi admin/operator untuk koreksi. |
