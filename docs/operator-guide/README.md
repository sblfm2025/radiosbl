# Panduan Operator

## Fungsi
Panduan ini membantu operator memantau streaming, Live/OB, request lagu, dan koordinasi jadwal.

## Cara Mengakses
Login sebagai operator, lalu gunakan dashboard, `Streaming`, `Live/OB`, `Request`, dan `Jadwal`.

## Workflow
1. Buka dashboard untuk melihat status siaran dan briefing.
2. Buka `Streaming` untuk cek player dan program berjalan.
3. Buka `Live/OB` untuk checklist perangkat, rundown, dan link koordinasi.
4. Buka `Request` untuk membantu penyiar saat on-air.
5. Buka `Jadwal` untuk melihat program berikutnya.

## Catatan Penting
- Pastikan link YouTube/Discord benar sebelum Live/OB.
- Gunakan checklist agar tidak ada alat yang tertinggal.
- Saat on-air, prioritaskan info yang berdampak langsung pada siaran.

## Troubleshooting
| Masalah | Solusi |
| --- | --- |
| Streaming tidak aktif | Buka halaman Streaming dan cek koneksi. |
| Link Live/OB kosong | Isi link sebelum event disimpan. |
| Request menumpuk | Bantu status antrean atau koordinasikan dengan penyiar. |
