# REQUIREMENTS_ANALYSIS.md

## Functional Requirements

### Auth
- Login/logout.
- Role-based access.
- Protected routes.

### Absensi
- Check-in/check-out.
- Selfie kamera.
- GPS dan radius kantor/studio.
- Upload selfie ke Google Drive.
- Rekap absensi.

### Jadwal Siaran
- CRUD program.
- CRUD jadwal.
- Tukar jadwal antar penyiar.
- Approval admin.

### Liputan
- Assignment reporter.
- Upload dokumentasi.
- Status liputan.
- Ringkasan AI.

### Live Broadcast / OB
- Jadwal event.
- Kru.
- Checklist alat.
- Rundown.
- Link YouTube dan Discord.

### Pengaduan
- Form publik.
- Kategori.
- Status penanganan.

## Non Functional Requirements

- Mobile-first.
- Ringan di Android.
- Free-tier friendly.
- Aman dengan Firestore Rules.
- Modular dan mudah dikembangkan.
