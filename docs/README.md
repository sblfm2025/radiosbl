# LPPL Radio Suara Bumi Lasinrang Management System

### "Suara Pinrang, Suara Kita"

LPPL Radio Suara Bumi Lasinrang Management System adalah aplikasi berbasis web
dan mobile Progressive Web App (PWA) yang dirancang untuk mendukung operasional
radio modern secara terintegrasi, profesional, dan real-time.

Aplikasi ini menjadi pusat kendali digital untuk manajemen penyiar, karyawan,
jadwal siaran, live broadcast, liputan, streaming radio, hingga pelayanan
masyarakat dalam satu platform terpadu yang modern dan mudah digunakan.

Dibangun dengan pendekatan **mobile-first**, aplikasi ini dioptimalkan untuk
penggunaan sehari-hari melalui smartphone Android maupun desktop, sehingga cocok
digunakan oleh penyiar, reporter, operator studio, admin, hingga pimpinan radio.

---

## Fungsi Utama Aplikasi

### 1. Manajemen Karyawan dan Penyiar

Mengelola data pegawai dan penyiar radio secara digital dan terpusat.

Fitur:

- Data profil pegawai dan penyiar
- Role dan permission management
- Status aktif/nonaktif pegawai
- Riwayat aktivitas pengguna
- Dashboard berdasarkan role

Role pengguna:

- Super Admin
- Admin
- Pimpinan
- Penyiar
- Reporter
- Operator
- Karyawan
- Publik

---

### 2. Sistem Absensi Modern

Sistem absensi berbasis lokasi dan foto selfie untuk memastikan kehadiran valid
dan real-time.

Fitur:

- Check-in dan check-out
- Foto selfie langsung dari kamera
- Validasi GPS dan geofence
- Rekap absensi otomatis
- Riwayat absensi harian/bulanan
- Monitoring keterlambatan
- Validasi radius kantor/studio

Teknologi:

- Geolocation API
- Camera Capture
- Google Drive API
- Firebase Firestore

---

### 3. Jadwal Siaran Digital

Mengatur seluruh jadwal program radio secara modern dan fleksibel.

Fitur:

- Kalender siaran
- Jadwal harian/mingguan/bulanan
- Manajemen program siaran
- Penjadwalan penyiar dan operator
- Reminder siaran
- Status siaran real-time

Fitur khusus:

- Penyiar dapat mengajukan tukar jadwal
- Persetujuan admin secara digital
- Riwayat perubahan jadwal

---

### 4. Live Broadcast dan OB Management

Mendukung pengelolaan siaran luar studio (Outside Broadcast/OB) secara
profesional.

Fitur:

- Event OB management
- Penjadwalan kru
- Rundown acara
- Checklist perlengkapan
- Lokasi kegiatan
- Dokumentasi kegiatan
- Catatan teknis lapangan

Integrasi:

- YouTube Live
- OBS Studio
- Discord Coordination

---

### 5. Streaming Radio Digital

Menyediakan akses streaming radio modern langsung dari aplikasi.

Fitur:

- Live streaming player
- Informasi siaran aktif
- Nama penyiar aktif
- Program yang sedang tayang
- Mini player modern
- Live waveform visualizer

---

### 6. Info Liputan dan Newsroom

Memudahkan koordinasi reporter dan liputan lapangan.

Fitur:

- Penugasan liputan
- Deadline liputan
- Upload foto, video, dan audio
- Arsip dokumentasi
- Status progres liputan
- Ringkasan otomatis menggunakan AI

Status workflow:

- Assigned
- In Progress
- Submitted
- Reviewed
- Published

---

### 7. Sistem Pengaduan dan Saran Publik

Menyediakan layanan aspirasi masyarakat secara digital.

Fitur:

- Form pengaduan publik
- Kategori pengaduan
- Tracking status
- Balasan admin
- Klasifikasi AI
- Statistik pengaduan

---

### 8. Integrasi Artificial Intelligence (Gemini AI)

Memanfaatkan AI untuk meningkatkan produktivitas operasional radio.

Fitur AI:

- Generator naskah siaran
- Ringkasan liputan otomatis
- Ide tema program radio
- Klasifikasi pengaduan masyarakat
- Analisis sentimen
- Bantuan penulisan konten

---

### 9. Integrasi YouTube dan Discord

Mendukung koordinasi siaran digital modern.

YouTube:

- Embed YouTube Live
- Monitoring live event
- Integrasi streaming event

Discord:

- Voice coordination room
- Notifikasi kru
- Komunikasi teknis live broadcast

---

### 10. Arsip Digital

Penyimpanan dokumentasi dan file operasional radio secara terorganisir.

Penyimpanan:

- Google Drive API
- Arsip foto
- Arsip audio
- Arsip video
- Arsip dokumen
