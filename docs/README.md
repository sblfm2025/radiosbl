## Aturan Pemeliharaan

- Catat perubahan signifikan di `CODEX_SESSION_LOG.md`.
- Update `HANDOFF.md` bila ada perubahan status besar.
- Jangan menaruh secret, token, atau file `.env.local` di dokumentasi.
- Gunakan gambar dari `public` untuk dokumentasi visual agar path stabil.
