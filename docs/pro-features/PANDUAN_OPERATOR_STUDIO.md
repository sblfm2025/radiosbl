# Panduan Operator Studio — Fitur Pro Radio SBL

Dokumen ini menjelaskan cara menggunakan fitur-fitur baru yang dirancang untuk memudahkan pekerjaan Operator Studio Radio SBL.

---

## 1. Studio Inbox — Mengelola Request Lagu

Studio Inbox adalah pusat semua request lagu dan salam udara dari pendengar.

**Cara menggunakan:**
1. Klik **Studio Inbox** di menu navigasi.
2. Tab **Request Lagu** menampilkan semua request yang masuk dengan status:
   - 📥 **Submitted** — baru masuk, belum dibaca.
   - 👁️ **Read** — sudah dibaca operator.
   - 🎵 **Queued** — masuk antrian putar.
   - ✅ **Played** — sudah diputarkan.
   - ❌ **Rejected** — ditolak/tidak relevan.
   - 🗂️ **Archived** — diarsipkan.
3. Klik request untuk membuka detail dan ubah statusnya.
4. Gunakan **Filter Status** untuk fokus pada kategori tertentu.

**Tips cepat:**
- Ubah status ke **Played** segera setelah lagu diputarkan agar pendengar mendapat notifikasi.
- Gunakan **Rejected** dengan catatan alasan yang sopan jika request tidak bisa dipenuhi.

---

## 2. Salam Udara — Dedikasi Pendengar

1. Klik **Salam Udara** di menu navigasi.
2. Lihat daftar salam dari pendengar beserta pesan dan nama penerima.
3. Salam dapat di-archive setelah dibacakan di udara.
4. Filter berdasarkan program aktif untuk efisiensi.

---

## 3. Checklist Pra-Siaran

Sebelum program dimulai, lengkapi checklist kesiapan teknis:

1. Buka halaman **Rundown** program yang akan siaran.
2. Klik **Checklist Pra-Siaran** di bagian bawah rundown.
3. Centang setiap item yang sudah siap:
   - Mikrofon
   - Koneksi internet
   - Jingle intro
   - Audio backsound
   - dll.
4. Jika ada kendala, tambahkan catatan di kolom **Catatan Teknis**.
5. Klik **Simpan** untuk menandai checklist selesai.

---

## 4. Log Teknis Siaran

Setelah siaran selesai, catat laporan teknis:

1. Buka menu **Log Siaran**.
2. Klik **Tambah Log Baru**.
3. Isi:
   - Program yang siaran.
   - Jam mulai dan selesai aktual.
   - Topik-topik yang dibahas.
   - Kendala teknis (jika ada).
4. Klik **Simpan**.

Log ini digunakan sebagai arsip siaran dan referensi evaluasi program.

---

## 5. Pengajuan Tindakan yang Memerlukan Persetujuan

Beberapa tindakan sensitif memerlukan persetujuan Admin sebelum dapat dieksekusi, antara lain:
- Publikasi podcast/video baru.
- Pengiriman notifikasi massal ke pendengar.
- Perubahan jadwal siaran utama.

**Cara mengajukan:**
1. Lakukan tindakan tersebut (misalnya klik "Publikasikan").
2. Sistem otomatis membuat pengajuan dengan status **Pending**.
3. Admin akan menerima notifikasi di Antrean Persetujuan.
4. Tunggu konfirmasi dari Admin sebelum konten aktif.

---

## 6. Tips Efisiensi Operator

- Buka **Studio Inbox** pertama kali saat mulai shift.
- Segera update status request lagu agar penyiar tahu mana yang sudah diproses.
- Isi log siaran sesegera mungkin setelah siaran selesai, saat detail masih segar.
- Jika ada masalah teknis yang berulang, catat di Log Siaran dengan detail lengkap.
