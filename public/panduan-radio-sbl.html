PWA install experience

Pasang RadioSBL seperti aplikasi native.

RadioSBL adalah Progressive Web App. Pengguna bisa membuka lewat browser, tetapi pengalaman terbaik didapat saat aplikasi dipasang ke layar utama.

01

Android Chrome

  1. Buka radiosbl.web.app di Google Chrome.
  2. Tekan tombol Install RadioSBL App pada layar login jika tersedia.
  3. Jika prompt tidak muncul, buka menu titik tiga lalu pilih Install app atau Tambahkan ke layar utama.
  4. Konfirmasi pemasangan dan buka dari ikon RadioSBL.

iPhone Safari

  1. Buka aplikasi memakai Safari.
  2. Tekan tombol Share.
  3. Pilih Add to Home Screen.
  4. Tekan Add, lalu buka dari ikon di Home Screen.
Kenapa perlu install?

Lebih cepat dibuka, tampilan fullscreen, akses lebih mudah untuk penyiar yang sering berpindah antara dashboard, jadwal, request, dan naskah.

FAQ modern

Solusi cepat untuk kendala umum.

Gunakan FAQ ini sebelum menghubungi admin teknis. Banyak masalah mobile selesai lewat izin browser atau refresh ringan.

14
Jadwal saya kosong, kenapa?
Akun mungkin masih berstatus tamu, role belum diset admin, atau jadwal belum dihubungkan dengan nama udara Anda.
GPS absensi tidak akurat?
Aktifkan lokasi presisi tinggi, izinkan lokasi untuk browser, lalu coba dekat area terbuka selama beberapa detik.
Tombol install tidak muncul?
Gunakan menu browser: Chrome Android lewat titik tiga, Safari iPhone lewat tombol Share lalu Add to Home Screen.
Mini player tidak muncul di dashboard?
Itu memang sengaja. Dashboard, Streaming, dan Podcast punya player utama masing-masing agar tidak ada player ganda.
Request lagu belum berubah realtime?
Periksa koneksi internet, tekan sinkronkan, lalu pastikan status request belum masuk ke riwayat.
Teleprompter terasa terlalu cepat?
Turunkan speed, pause sebentar, lalu lanjutkan. Siapkan naskah pendek per segmen agar pembacaan lebih stabil.
